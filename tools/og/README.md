# תמונת השיתוף (og-image.png)

זו התמונה שמופיעה כשמישהו משתף קישור לאתר בוואטסאפ / פייסבוק.

**להפיק מחדש** (אחרי שינוי מסר או מיתוג):
1. לערוך את `og.html`.
2. `node tools/og/shoot.mjs` — מייצר `og-image.png` באותה תיקייה.
3. להעתיק ל-`public/og-image.png`.

הגופנים בתיקייה `fonts/` הם עותק מקומי מ-`node_modules/@fontsource` —
בלעדיהם הכותרת בעברית תיפול לגופן מערכת ותיראה אחרת.

# סרטוני ההדרכה

צילום של האפליקציה האמיתית, עם נתוני דמו וכתוביות בעברית, בלי קול.
הכול כאן **מחוץ למוצר** — `npm run build` לא נוגע בתיקייה הזו.

## למה נתוני דמו ולא החשבון האמיתי

הסרטון מופץ בוואטסאפ. צילום של החשבון האמיתי היה מציג שמות של קטינים,
נוכחות שלהם ומשוב אישי עליהם. `harness/mockSupabase.js` מחליף את
`supabaseClient` בנתוני דמו: מאמן בשם דני אבידן, נערים ב׳, 12 שחקנים
בדויים, היסטוריית נוכחות של ארבעה אימונים, שתי תוכניות אימון ושמונה תרגילים.

## הרצה

שני מסופים.

**1. שרת ההרנס** (האפליקציה מול המוק):

```bash
npx vite --config tools/tutorial/harness/vite.config.mjs
```

**2. הצילום:**

```bash
node tools/tutorial/record.mjs
```

קטע בודד:

```bash
node tools/tutorial/record.mjs roster
```

הקטעים: `home` · `teams` · `work` · `fromCommunity` · `schedule` · `review` · `community` · `finder` · `messages` · `media` · `help`.

   אחרים שיתפו הם הדבר שהכי חבל לפספס, והם היו חסרים לגמרי בגרסה הקודמת.

## mp4 מול webm

⚠ ה-ffmpeg שמגיע עם Playwright הוא בילד מקוצץ (`--disable-everything`):
webm/VP8 בלבד, **בלי libx264 ובלי מוקסר mp4**.

`record.mjs` מחפש ffmpeg מלא ב-PATH, ב-`C:/Program Files/ffmpeg/bin`,
במשתנה הסביבה `FFMPEG`, וגם ישירות בתיקיית החבילות של winget — כי ה-PATH
מתעדכן רק אחרי פתיחת מסוף חדש. אם נמצא, הפלט הוא mp4; אחרת webm.

להתקנה (בוצעה במחשב הזה ב-25.8.2026):

```bash
winget install Gyan.FFmpeg
```

שלושת הדגלים `libx264` + `yuv420p` + `+faststart` נדרשים כדי שהסרטון
יתנגן באייפון ובוואטסאפ — לא רק ייווצר.

## לשנות נוסח

הכתוביות הן טקסט ב-`record.mjs`, בתוך `CLIPS`. אין צורך בעורך וידאו:
משנים את המחרוזת ומריצים מחדש את הקטע.

## מלכודות שכבר נתפסו

- **הסיור המודרך נפתח באמצע צילום.** המוק כותב `tour_v1` ו-`onboarded_v1`
  ל-localStorage בטעינה, כדי שלא יקפוץ.
- **מודל סקירת האימון גולל בפנים** (`.sd-scroll`) — גלגלת על הדף לא מזיזה
  בו כלום. בשביל זה יש `scrollIn()`.
- **מודל שנשאר פתוח חוסם את הקטע הבא** בסרטון הארוך. `reset()` סוגר הכול
  וחוזר לבית בין קטעים.
- **סמן העכבר לא מוקלט** ב-Playwright. במקומו יש טבעת כתומה קצרה על היעד
  לפני כל לחיצה (`__spot`).
- **שחקן «נעדר» עם ציון עומס** נראה כמו באג בסרטון. `session_effort` במוק
  מסנן את הנעדרים.

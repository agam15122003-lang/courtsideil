# סרטון התדמית

הסרטון עצמו חי בפרויקט Claude Design `facda603-8e81-4956-a87d-a5cec2036dae`.
התיקייה הזו היא העותק בגיט: הקופי, התסריט והנכס שנוצר כאן.

| קובץ | מה זה |
|---|---|
| `CourtSide - סרטון תדמית.dc.html` | רשימת הסצנות והמשכים |
| `courtside-promo.jsx` | הסרטון עצמו — כל הטקסטים והתנועה |
| `narration-script.md` | הקריינות, ומה נפסל בבדיקת עובדות |
| `courtside-video-prompt.md` | פרומפט להעברה למי שמכין סרטון חדש |
| `assets/screen-games.png` | לוח משחקי האימון — נוצר כאן, ראה למטה |

הקבצים `animations-v3.jsx`, `tweaks-panel.jsx` ו-`support.js` הם סקאפולד
של Claude Design ולא הועתקו לכאן — הם לא משתנים.

## המבנה: בעיה ואז פתרון

לבקשת הבעלים. כל ביט הוא זוג: **שורת בעיה בגוף ראשון** (מה שמאמן אומר
לעצמו) ואז **שורת פתרון בגוף שני** (מה שאנחנו אומרים לו). ההיפוך הוא מה
שגורם לזה להישמע כמו שיחה.

שישה ביטים בלבד — «רק הדברים המרכזיים». ארבעה כותבים עצמאיים התכנסו
לאותם חמישה פיצ'רים, ואליהם נוספה המסגרת הפותחת.

## מגבלת אורך שנמדדה, לא נוחשה

שורת הבעיה ב-66px מחזיקה **36 תווים בשורה אחת**. מעבר לזה היא נשברת
לשתיים, בלוק הכיתוב גדל מ-228 ל-298 פיקסל, והוא נכנס לתוך הטלפון.

הגיאומטריה נגזרה מזה: `phY` 780, `phScale` 1.38, כיתוב ב-`bottom: 4.5%`
— 36 פיקסל מרווח גם כשהפתרון נשבר לשתי שורות. **כל שינוי בטקסט מעבר
ל-36 תווים בשורת בעיה שובר את הפריים.**

המדידה: `scratchpad/capmeasure.html` + Playwright ב-1080×1920.

## `screen-games.png` — נכס שנוצר כאן

לוח משחקי האימון הוא אחת משלוש הדוגמאות שהבעלים כתב בעצמו, ולא היה לו
צילום מסך בפרויקט. נוצר מההרנס:

```bash
npx vite --config tools/tutorial/harness/vite.config.mjs
```

ואז ניווט ל«חיפוש מאמנים» ← «משחקי אימון», צילום מלא ברוחב 784 (כמו שאר
הצילומים בפרויקט). שלוש הבקשות הפתוחות הן נתוני דמו מ-`mockSupabase.js`,
לא מאמנים אמיתיים.

## ⚠ הרקע — למה הוא כבר לא צילום

הרקע היה `public/images/hero/hero-32c9130b-lg.webp`, במסך מלא. התמונה
נמשכה אוטומטית מ-Openverse (קומיט `5d527bb`) עם `license=cc0,pdm,by`.

**CC BY מחייב ייחוס**, והמניפסט שאמור היה לשמור יוצר ורישיון לכל תמונה
— `src/data/images.json` — **לא קיים בריפו**. כלומר אין דרך לדעת איזו
מ-83 התמונות היא CC BY ומי היוצר שלה.

83 התמונות (6.4MB) לא בשימוש בשום מקום ב-`src/`, ולכן האתר לא מפר כלום.
הסרטון היה השימוש האמיתי הראשון. הוחלף בגרדיאנט נייבי מצויר בקוד.

**כדי להחזיר צילום רקע:** להריץ מחדש את `scripts/fetch-images.mjs` כדי
לשחזר את המניפסט, לבדוק את הרישיון של התמונה הספציפית, ולהוסיף קרדיט
אם היא CC BY.

## מה נפסל בבדיקת עובדות

הקופי נכתב בלי גישה לקוד ואז נבדק מולו. שלוש טענות נפלו — «חלקים
וזמנים» שלא קיימים, «מעתיק אליך תרגיל» שלא אפשרי (רק תוכנית שלמה),
ו«מאמנים אחרים כותבים לך» שהיא הבטחה על התנהגות של אנשים אחרים.
הפירוט המלא ב-`narration-script.md`.

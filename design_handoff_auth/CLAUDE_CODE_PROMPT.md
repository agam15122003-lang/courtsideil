# הוראות ל-Claude Code — שילוב מסכי ההרשמה והכניסה של CourtSide

> העתק את כל הבלוק הזה לתוך Claude Code בתיקיית הריפו `courtsideil`, יחד עם התיקייה `design_handoff_auth/`.

---

אני מוסיף לאפליקציה עיצוב חדש למסכי הכניסה/הרשמה/איפוס. בתיקייה `design_handoff_auth/` יש:

- `README.md` — מפרט עיצוב מלא (מסכים, מידות, צבעים, טיפוגרפיה, מצבים, טוקנים). **קרא אותו קודם, במלואו.**
- `design/Courtside Auth.dc.html` — הפרוטוטייפ ב-HTML. זו **אסמכתה עיצובית, לא קוד לייצור.** אל תעתיק ממנו JSX, אל תייבא אותו, ואל תוסיף אותו ל-build. פתח אותו בדפדפן כדי לראות את המטרה, ותרגם אותה לסטאק הקיים שלנו.

## מה לעשות

מסכי הכניסה הקיימים ב-`src/Auth.jsx` ו-`src/ResetPassword.jsx` הם דסקטופ-first (`auth-split` עם פאנל תמונה בצד). העיצוב החדש הוא מובייל-first (390×844) ומוסיף מסכים שלא קיימים בקוד. **המשימה: לשלב את העיצוב החדש בתוך הזרימה הקיימת** — לא לכתוב אפליקציה חדשה, לא לשבור את מה שעובד.

לפי סדר:

1. **קרא לפני שאתה כותב** — `DESIGN.md` (חוקי הבית), `src/App.jsx` (השערים לפני הכניסה), `src/Auth.jsx`, `src/ResetPassword.jsx`, `src/i18n.js`, `src/DirIcon.jsx`, `src/players.js`. אל תשנה קובץ לפני שקראת אותו.
2. **הצג לי תוכנית** — טבלה של: איזה מסך מהעיצוב → לאיזה קובץ הוא נכנס → נוצר/משתנה/נמחק. **חכה לאישור שלי לפני כתיבת קוד.** אם משהו במפרט מתנגש עם הקוד הקיים, תעצור ותשאל — אל תנחש.
3. **מיין את שלוש ההחלטות הפתוחות** שמופיעות בסוף ה-README (תפקיד ההורה, שחקן בלי קוד, סיסמה מול קוד-למייל). הן משפיעות על היקף העבודה — תשאל אותי, אל תחליט בעצמך.
4. **יישם בפעימות קטנות**, מסך אחד לכל commit, עם הודעת commit בעברית שאומרת מה נכנס. עצור אחרי המסך הראשון (`signin`) כדי שאאשר את הכיוון לפני שתמשיך.

## חוקי ברזל — מ-DESIGN.md, לא להמציא מחדש

- **אין hex גולמי ב-JSX או ב-CSS חדש.** כל צבע דרך טוקן. ב-README יש טבלת מיפוי מכל hex בפרוטוטייפ לטוקן שלו — השתמש בה. אם צבע לא ממופה לטוקן קיים, תעצור ותשאל; אל תמציא טוקן חדש בשקט.
- **CSS חדש = בלוק append בסוף `src/index.css`** עם באנר מתוארך. לא לערוך בלוקים ישנים (הקובץ 563KB, הכללים המאוחרים מנצחים).
- **RTL**: מספרים/קודים/מיילים תמיד `dir="ltr"` עם `text-align: start`; חצים דרך `src/DirIcon.jsx` בלבד (`ArrowFwd`/`ChevronBack`), אין `ArrowLeft` ישירות; מרווחים לוגיים (`margin-inline-*`), לא left/right.
- **כל טקסט דרך `L('עברית','English')`** מ-`src/i18n.js`. אין מחרוזת קשיחה, בשום שפה.
- **אייקונים**: `lucide-react` בלבד, כמו בקוד הקיים. אין אימוג'י ב-UI.
- **שלושת המצבים** לכל מסך ששולף נתונים: טעינה, ריק, שגיאה. שגיאה ≠ "אין נתונים", ולכל שגיאה יש דרך התאוששות.
- **44px מינימום** ליעד מגע, 11px מינימום לגופן, כפתור ראשי אחד למסך.
- אנימציות: 150–250ms, ומכובות גם ב-`prefers-reduced-motion` וגם ב-`html.a11y-motion`.

## לא לגעת

- אין שינוי בסכימת Supabase ואין קובץ SQL חדש בשביל העיצוב הזה. אם מסך דורש שדה שלא קיים (למשל שם מועדון בהרשמה) — תגיד לי, ואני אחליט.
- אין החלפה של ספריות ואין הוספת תלויות. `lucide-react` + React + Supabase שקיימים — זה מה שיש. אם נראה לך שצריך משהו חדש, תשאל.
- `translateError()` ב-`Auth.jsx` הוא נכס — הרחב אותו, אל תכתוב מחדש. כל שגיאה חדשה מהעיצוב צריכה להיכנס אליו כמו הקיימות.
- אל תמחק את הפאנל הקולנועי (`auth-hero-panel`) — ב-README מוסבר איך הוא נשאר לדסקטופ.
